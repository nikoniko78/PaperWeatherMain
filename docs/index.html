Feature requests

Have an idea for YAWOS?

Read the short guide below, then write your request in the form. It is posted on GitHub as a public request.

Write a request

Before you write

  1. Update to the newest version in Settings → Updates manager. Your idea may already exist.
  2. Send one idea per request so each can be tracked on its own.
  3. Describe what you want to happen. How it gets built is up to the maintainer.

Good requests

  • Start with the problem you want solved
  • Describe what you would expect to see or press
  • Mention the screen, such as forecast, 7-day or a settings menu
  • Note your firmware version from the footer of the main screen
  • Describe the layout in words when it is visual

Please avoid

  • Several unrelated ideas in one post
  • Repeating the same request many times
  • Vague titles such as "improve it"
  • Bug reports; say what you expected instead
  • Demands or deadlines; this is a hobby project

Formatting recommendations

  • Title: short and specific, in the form Area: what you want.
  • Structure: fill in the three boxes: a one-line summary, what it should do, and why it helps.
  • Lists: start lines with - for several behaviours and 1. for steps.
  • Buttons and menus: wrap names in backticks, such as Experimental Features.
  • Layouts: describe where things go on the 540 × 960 screen, for example "under the high/low row".
  • Be mindful of the display: mention if an idea needs frequent refreshes, since full refreshes are slow and flash.

Example:

Summary: 7-day: show sunrise and sunset per day

What should it do?
- Show sunrise and sunset under each day's high/low
- Keep it hidden when Simple display is on

Why would it help?
I plan morning walks and want to see daylight at a glance.

Ground rules

  • Be kind and constructive. Disagree with ideas, not people.
  • Stay on topic in each thread.
  • Do not include Wi-Fi passwords, API keys or private locations.
  • A request is a suggestion, not a promise. Popular and small, focused ideas are usually picked up first.
Requests are posted publicly, so leave out personal information.
