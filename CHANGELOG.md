## Version 4.0.0+ Vita (public)

- Added Dark Mode flash and refresh features so that it may work on worn out displays.
- Added refresh method changes to increase customizability and UI speed.
- Made Dark Mode apply to boot cycle.
- Added a [public Recommend Features / Bug Reports page](https://nikoniko78.github.io/PaperWeatherMain/).
- Fixed bugs with the Theme Store and images not being inverted in dark mode.
- Settings menu now looks better and contains new features like data usage and better Wi-Fi configs.

### Nightly Updates
Contain experimental features coming to public soon. Changes will be shown on a public release. If you would like access to nightly updates, please toggle on your device via ***Settings -> Updates Manager -> Nightly Updates.***
